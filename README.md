# DIY-PEDALBOARD.public

Public build-log site for the DIY MIDI Music Workstation Pedal Board project.

- [`documentation-github-page/`](documentation-github-page) — the Hugo (Stack theme) build-log
  site: project overview, hardware/electronics notes, design decisions, tooling, and a build
  timeline. Deployed to GitHub Pages via `.github/workflows/hugo.yml` on every push to `main`.
